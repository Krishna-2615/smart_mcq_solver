# smart_mcq_solver

Smart MCQ Solver: Hybrid RAG & Ensemble LLM Pipeline
📌 Project Overview
The Smart MCQ Solver is an advanced machine learning pipeline designed to answer complex domain-specific multiple-choice questions (MCQs), specifically targeting Physics. Instead of relying on a single model, this project employs a Knowledge-Augmented Ensemble Approach, combining a custom Knowledge Graph, semantic vector retrieval, and a blend of three distinct neural architectures to maximize prediction accuracy.
